### Milestone notes

- **v3 compute series (Dsv3 General Purpose, Esv3 Memory Optimized)** — v3 was the launch compute series for flexible server; it reached GA with the service.
- **Burstable tier, B1ms / B2s / B2ms** — The original burstable sizes; GA with flexible server.
- **Intel v5 compute series (Ddsv5 General Purpose, Edsv5 Memory Optimized)** — Announced 2023-06-05 covering the May 2023 release; listed in the May 2023 release notes.
- **AMD v5 compute series (Dadsv5 General Purpose, Eadsv5 Memory Optimized)** — Rolled out during 2023 after the Intel v5 series; reserved capacity for both Intel and AMD v5 SKUs landed in September 2024. Exact GA month not confirmed.
- **v6 compute series (Ddsv6 / Dadsv6 General Purpose, Edsv6 / Eadsv6 Memory Optimized)** — PUBLIC PREVIEW as of the catalog date. Scaling between Burstable and v6 is not supported, and virtual network integration is not supported on v6.
- **Azure Database for PostgreSQL single server (Basic / General Purpose / Memory Optimized)** — RETIRED on 2025-03-28. Listed for historical completeness only; not orderable.
